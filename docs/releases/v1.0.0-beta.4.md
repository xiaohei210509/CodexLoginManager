# Codex Login Manager v1.0.0-beta.4

## 中文说明

适用于 macOS 的 Codex 登录诊断与本地听写补丁管理工具。此版本将听写补丁直接内置到管理器中，新增按代码结构自动适配和 Codex 官方更新流程，无需另外下载补丁工具。

### 本版更新

- **补丁内置**：包含原生补丁引擎、Acorn 解析器和适配规则，无需 Node.js、外部脚本或手动选择资源目录。首次开启时从本机已安装的官方客户端生成经过验证的备份与补丁副本。
- **跨版本自动适配**：按代码结构识别目标，而非绑定每版的压缩文件名或固定偏移。每个构建独立保存适配结果与备份；发现多义匹配、未知修改或不兼容结构时拒绝套用。上游结构大改仍可能需要更新规则。
- **更新 Codex**：仅在检测到符合系统与架构要求的官方更新时显示按钮。确认后下载完整 ZIP，验证长度、Ed25519 签名和 OpenAI 应用签名，再正常退出、安装并重新打开。不会强制结束 Codex。
- **更新后尝试重打补丁**：原先启用的补丁会在新版本上重新适配；若不兼容，则保留官方新版并显示提示，不强行应用。
- **更新查询调整**：固定使用 `plan_type=plus`、`beta=false` 和管理器独立的随机安装标识。这只是更新查询参数，不会读取或改变实际订阅，也不保证与官方客户端的个性化更新结果始终一致。
- **可靠性改进**：并行读取子进程的标准输出与错误输出，避免工具输出较多时因管道写满而卡住；保留进程锁、事务替换、回滚和中断恢复。
- **原有登录功能保留**：本地检查认证状态，调用官方 CLI 完成浏览器登录，并在显示命令输出前对已知凭据模式脱敏。界面支持简体中文和英文。

### 下载与安装

1. 下载本页附件 `CodexLoginManager-v1.0.0-beta.4-macOS-universal.zip`，可使用 `SHA256SUMS.txt` 校验。
2. 解压后将 `CodexLoginManager.app` 移入 `/Applications`。已有版本的用户先退出管理器，再替换旧版。
3. 打开管理器；如被 macOS 阻止，先尝试打开一次，再到“系统设置 > 隐私与安全性”中选择“仍要打开”并确认。不要全局关闭 Gatekeeper。

**系统要求**：macOS 14 或更新版本；同一安装包支持 Apple Silicon 与 Intel。登录诊断需要已安装的官方 Codex CLI；补丁功能需要可识别的官方桌面客户端。请预留数 GB 空闲空间用于本机备份与更新。

### 使用限制与隐私

- 本项目为独立社区预发布版，采用 **ad-hoc 签名，尚未获得 Apple Developer ID 签名或 Apple 公证**，并非 OpenAI 官方产品。
- 切换补丁前必须完全退出 Codex。开启补丁会修改已安装的 Codex 并使用本地签名，可能需要重新授权权限或登录，部分系统集成可能受影响。关闭时恢复该构建的已验证官方备份。
- 不保证所有未来版本兼容，也不保证账户、工作区或转写服务可用；实际听写效果仍需手动验证。本工具不是全局听写应用。
- 下载包不包含原版或修改版 Codex。备份和生成副本只保存在本机 `~/Library/Application Support/CodexLoginManager/DictationPatch`。
- 不上传认证凭据，不直接修改 `~/.codex/config.toml`，不包含遥测。更新检查仅访问官方更新服务，发送已安装版本、系统与架构信息及上述固定参数。不要在公开 Issue 中附带 `auth.json`、令牌或未脱敏日志。

## English

A native macOS utility for diagnosing Codex CLI authentication and managing a local dictation patch. This release embeds the patch engine directly in the manager, adds structural adaptation across compatible builds, and introduces a verified official Codex update workflow.

### What's New

- **Embedded patch engine:** Includes the native engine, Acorn parser, and adaptation rules. No Node.js, external script, or resource-folder selection is needed. The first enable creates verified original and patched copies from the official client installed on this Mac.
- **Adaptive compatibility:** Identifies code structure rather than pinning each build's minified filenames or fixed offsets. Plans and backups are separate for every build. Ambiguous matches, unknown modifications, and incompatible structures are refused. Major upstream changes may still require updated rules.
- **Update Codex:** The button appears only when an eligible official update is available. After confirmation, the manager downloads the full ZIP, verifies its length, Ed25519 signature, and OpenAI application signature, requests a normal quit, installs the update, and reopens Codex. It never force-quits Codex.
- **Patch reapplication after updating:** An enabled patch is adapted again for the new build. If adaptation fails, the official new build is retained with a warning instead of forcing the patch.
- **Update-query adjustment:** Checks use fixed `plan_type=plus` and `beta=false` parameters with a manager-specific random installation ID. This does not detect or change your subscription, and it does not guarantee the same result as the official client's personalized update check.
- **Reliability:** Reads subprocess stdout and stderr concurrently to avoid full-pipe deadlocks. Retains process locking, transactional replacement, rollback, and interrupted-change recovery.
- **Existing login tools retained:** Inspects local authentication state, delegates browser login to the official CLI, and redacts known credential patterns before displaying command output. The interface supports English and Simplified Chinese.

### Download and Install

1. Download the attached `CodexLoginManager-v1.0.0-beta.4-macOS-universal.zip`. Optionally verify it against `SHA256SUMS.txt`.
2. Unzip and move `CodexLoginManager.app` to `/Applications`. Quit an existing manager before replacing it.
3. Open the manager. If macOS blocks it, try opening it once, then use **System Settings > Privacy & Security > Open Anyway** and confirm **Open**. Never disable Gatekeeper globally.

**Requirements:** macOS 14 or later. One universal download supports Apple Silicon and Intel. Login diagnostics require an installed official Codex CLI; patch management requires a recognized official desktop client. Allow several GB of free disk space for local backups and updates.

### Limitations and Privacy

- This is an independent community prerelease, **ad-hoc signed, without Apple Developer ID signing or Apple notarization**. It is not an official OpenAI product.
- Fully quit Codex before switching the patch. Enabling modifies the installed Codex app and uses a local signature; permissions, sign-in, or system integrations may be affected. Disabling restores that build's verified official backup.
- Future-build compatibility, account/workspace eligibility, and transcription-service availability are not guaranteed. Verify actual dictation manually. This is not a system-wide dictation app.
- Official and modified Codex bundles are not distributed. Generated copies and backups remain locally in `~/Library/Application Support/CodexLoginManager/DictationPatch`.
- Credentials are not uploaded, `~/.codex/config.toml` is not directly modified, and there is no telemetry. Update checks contact official update services with the installed version, OS/architecture, and the parameters listed above. Never attach `auth.json`, tokens, or unredacted logs to public issues.
